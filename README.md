# HR Analytics Dashboard Using Microsoft Excel

## 📌 Project Overview

This project focuses on developing an interactive Human Resources (HR) Dashboard using Microsoft Excel to analyse employee data and present meaningful workforce insights.

The dashboard was created as part of my MBA coursework to apply Excel data analysis and visualisation techniques to an HR business scenario. It transforms raw employee data into an organised, interactive dashboard that supports workforce analysis and data-driven decision-making.

## 🎯 Project Objectives

The primary objectives of this project are to:

* Analyse employee distribution across different departments.
* Examine workforce distribution across designations.
* Compare average monthly salaries across departments.
* Explore employee information by gender and branch city.
* Analyse employee joining dates using a timeline.
* Develop an interactive dashboard for convenient exploration of HR data.

## 🛠️ Tools and Techniques Used

**Tool:** Microsoft Excel

**Techniques:**

* Data Organisation and Preparation
* Excel Formulas, including IF and COUNTIF
* Pivot Tables
* Pivot Charts
* Slicers for Interactive Filtering
* Timeline Filtering
* Dashboard Design and Data Visualisation

## 📊 Key Dashboard Features

### 1. Department-Wise Employee Distribution

Summarises the employee count across departments to provide an overview of workforce distribution.

### 2. Designation-Wise Employee Distribution

Displays the number of employees across different designations, including Executive, Senior Executive, and Trainee.

### 3. Department-Wise Average Monthly Salary

Compares average monthly salaries across departments to support an understanding of salary distribution within the organisation.

### 4. Interactive Slicers

Slicers allow users to filter the dashboard using available employee attributes, including branch city, gender, and employee name.

### 5. Date-Based Analysis

A timeline filter enables users to explore employee data based on the date of joining.

## 🔍 Business Applications

This dashboard demonstrates how Microsoft Excel can be used to support HR analysis by helping users:

* Understand workforce distribution across departments.
* Examine the composition of the workforce by designation.
* Compare average monthly salaries between departments.
* Explore employee records using interactive filters.
* Present HR information in a structured and accessible format.

The dashboard serves as a basic analytical tool for exploring workforce information. Further analysis would be required to draw conclusions about compensation equity, employee performance, or workforce effectiveness.
